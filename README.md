# OpsPilot AI — AI Operations OS (live demo)

A controlled AI operations control plane for incident remediation. **Mock-only — no real
infrastructure is ever touched.**

**Try it:** type `DEMO-001` and click **Plan Remediation** (safe auto-execute → verified).
Then try `DEMO-002` (needs approval) and `DEMO-008` (escalates — refuses to blame the wrong
deploy).

AI recommends → a deterministic policy engine decides → humans approve anything risky →
every fix is verified from telemetry and audited.

Source, evaluation, and case study: see the project repository.
